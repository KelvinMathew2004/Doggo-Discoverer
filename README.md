# 🐶 Doggo Discoverer

**Description:**  
Doggo Discoverer lets users explore dog breeds from all over the world! View breed details like weight, lifespan, and country of origin. Already familiar with a breed? Add it to a “ban list” to exclude it from future results. Fetch new doggos, see them one at a time, and manage your personalized banned breeds list for a tailored discovery experience.

---

## 🌟 Features

### 🐾 Discover Breeds
- **Fetch new dogs:** Click a button to get a new dog breed with consistent attributes and images.
- **Single result view:** Only one breed is displayed at a time, with attributes matching the image.
- **Randomized results:** Each API call generates a seemingly random new dog; repeats are rare.

### 🚫 Ban List
- **Clickable attributes:** Click a displayed attribute (like breed) to add it to the ban list.
- **Manage bans:** Clicking an attribute in the ban list immediately removes it.
- **Filter results:** Banned attributes prevent future API results from showing dogs with those values.

### 📋 History & Stats
- **Multiple attribute bans:** More than one type of attribute can be banned.
- **Session history:** View previously displayed dogs from the current session in a dedicated section.
- **Dynamic updates:** History updates instantly with each new API fetch.

### 🎨 Styling & UX
- **Interactive UI:** Smooth, responsive, and easy to navigate.
- **Engaging design:** Attributes are clickable, creating an interactive exploration experience.
